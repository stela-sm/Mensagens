# 💌 Gerados de Mensagens

Uma página web que gera mensagens de amor aleatórias, feita com carinho em HTML, CSS e JavaScript.

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts (Alegreya Sans, Open Sans, Shrikhand)
- Font Awesome

## ✨ Como usar

Basta abrir o `index.html` no navegador e clicar em **"Gerar Mensagem"** para exibir uma nova mensagem de amor.

Não é necessário instalar nada — o projeto roda direto no browser.

## 📁 Estrutura

```
Mensagens/
├── index.html
├── main.css
└── index.js
```
